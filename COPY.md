# Where to edit the on-page text

All the words on the checker live in three files. Edit, save, and the dev site
updates instantly; push to `main` to go live.

## `app/config.ts` — links & toggles
- **`BOOKING_URL`** (line 11) — the "Book a call" link. Empty → button shows a
  disabled placeholder.
- `VSL_URL` (line 8) — video embed (unused for now).
- `SCARCITY_TEXT` (line 16) — only shows if `SCARCITY_ENABLED` is true.

## `app/page.tsx` — the landing page around the checker
- **Eyebrow** — "For parents of Year 10–13 students" (line 15)
- **Headline** — "Is your path future-proof?" (lines 18–20; the highlighted word
  is inside the `<span>`)
- **Sub-headline** — "Search any job, degree or apprenticeship…" (line 24)
- **Footnote strip** — "Competition and openings are modelled estimates…" (line 38)
- **Footer** — copyright line (line 48)

## `app/checker/Checker.tsx` — everything inside the tool
- **Example chips** (the "Try:" row) — `EXAMPLES` array (line 39)
- **The "?" tooltip explanations** — `DEFS` object (lines 66–72). One string per
  metric: salary, openings, competition, ai_exposure, elasticity.
- **Search box placeholder** — line 123
- **Summary-card labels** — "Salary" / "Projected openings" / "AI exposure" (lines
  278–280) and "Projected openings" / "Competition" / "Avg salary" for degrees
  (lines 289+).
- **Table column headers** — "Occupation, Salary, Openings, Competition, AI risk,
  Elasticity" (lines 386–391)
- **AI-risk words** — `AI_BANDS` labels "Very low → Very high" (~line 50)
- **Elasticity words** — `EL_WORDS` = "Capped, Limited, Growing, Expanding" (line 61)
- **Entity-type chips** — `TYPE_LABEL` "Occupation / Degree / Apprenticeship" (line 33)
- **Call-to-action** — "The data shows the shape of it…" (line 324)
- **Toggle labels** — "Relevant / Similar / All jobs" (search for `Toggle`)

## Not editable on the page — the per-row data text
The one-line notes tied to each number (e.g. "£45,310 mean full-time pay…",
each occupation's elasticity reasoning) are generated by the data pipeline in
`../jobs/pipeline/build.py`. Change them there, then rebuild:
`uv run jobs/pipeline/build.py` (writes `public/data.json`).
